title: readelf와 xxd를 사용한 x86_64 elf 헤더 분석기
 
## elf 란 무엇인가?
 
 
구성:
elf header, program header table(or section header table)
header table의 오프셋은 elf header에 정의
 
## ELF 헤더
프로그램 기본 정보(endian, abi 등)
프로그램 헤더와 섹션헤더 정보를 기술함.
오프셋, 크기, 개수를 정의
 
 
## readelf & xxd
readelf는 elf 포맷의 파일정보를 표시하기 위한 gnu툴입니다.
xxd는 바이너리 파일을 16진수 덤프로 보여주는 툴입니다.
 
xxd를 사용해서 elf파일의 16진수 값을 출력하고, readelf와 비교하면서 살펴보겠습니다.
 
## 샘플 코드
실제 C 코드 컴파일로 생성된 ELF파일을 분석해보겠습니다.
```c
#include <stdio.h>
 
int g = 19;
 
int main(void) {
  int a = 0xff;
  printf("Hello, a=%d\n", a);
  return 0;
}
```
 
### ELF 헤더 파싱
```bash
$ readelf -h a.out
```
- EFL 헤더 정보를 표기한다.
 
 
헤더의 각 정보를 실제 바이너리 파일과 비교해보자.
 
#### e_indent
64비트 아키텍쳐이므로,
Elf64_Addr (uint64_t) 8-byte
 
Elf32_Ehdr 라는 구조체에 저장됨.
첫번째 16바이트는 e_indent 값으로 
 
```
  Magic:   7f 45 4c 46 02 01 01 00 00 00 00 00 00 00 00 00
  Class:                             ELF64
  Data:                              2's complement, little endian
  Version:                           1 (current)
  OS/ABI:                            UNIX - System V
  ABI Version:                       0
```
 
바이너리 값을 확인해보자.
```bash
$ xxd -g 1 -l 16 a.out
00000000: 7f 45 4c 46 02 01 01 00 00 00 00 00 00 00 00 00  .ELF............
```
1바이트씩, 16바이트를 표기한다.
 
#### e_type
 
```bash
Type:                              DYN (Position-Independent Executable file)
```
```bash
$ xxd -s 16 -g 1 -l 2 a.out
00000010: 03 00
```
offset = 16
 
 
#### e_machine
```bash
Machine:                           Advanced Micro Devices X86-64
```
 
```bash
$ xxd -s 18 -g 1 -l 2 a.out
00000012: 3e 00 
```
3e는 EM_X86_64 이다.
 
#### e_version
4바이트 값
```
Version:                           0x1
```
 
```
00000014: 01 00 00 00
```
 
#### e_entry (Entry point address)
Elf64_Addr 이므로, uint64_t 크기이다.
8바이트 값을 확인
```
Entry point address:               0x1060
```
```
$ xxd -s 24 -g 1 -l 8 a.out
00000018: 60 10 00 00 00 00 00 00
```
endian이 달라서 출력 순서가 다르다!
 
#### e_phoff (Start of program headers)
Elf64_Off 이므로 uint64_t 크기(8-byte)
```
Start of program headers:          64 (bytes into file)
```
```
$ xxd -s 32 -g 1 -l 8 a.out
00000020: 40 00 00 00 00 00 00 00
```
0x40 = 64
 
#### e_shoff (Start of section headers)
```
Start of section headers:          14008 (bytes into file)
```
 
```
$ xxd -s 40 -g 1 -l 8 a.out
00000028: b8 36 00 00 00 00 00 00
```
0x35b8 = 14008
 
#### e_flags (Flags)
type: uint32_t
```
Flags:                             0x0
```
 
#### e_ehsize (Size of this header)
type: uint16_t
```
Size of this header:               64 (bytes)
```
ELF 헤더 사이즈?
16 + (2*8) + (4*2) + (8*3)
= 64 (OK)

```
