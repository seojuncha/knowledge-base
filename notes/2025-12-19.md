title: 섹션헤더 확인하기
 
x86기반 호스트 시스템에서는 gcc 기본동작 및 링크/로더 때문에 ELF파일 정보를 읽고 분석하기 조금 난해합니다.
그래서 arm 어셈블리 코드를 컴파일한 결과로 분석해봅니다.
 
## 간단 ARM 어셈블리 코드
 
```armasm
  .syntax unified
  .arch armv4t
  .arm
  .text
  .global _start
_start:
  nop
  b .
```
해당 코드는 메타데이터 정의와 2개의 명령어만 수행합니다.

컴파일:
```bash
$ clang-21 --target=armv4t-none-eabi -c main.s -o main.o -march=armv4t -marm
```
 
```bash
$ llvm-readelf-21 -l main.o
 
There are no program headers in this file.
 
 Section to Segment mapping:
  Segment Sections...
   None   .strtab .text .ARM.attributes .symtab
```
- relocation object파일로 생성하면 프로그램 헤더는 없습니다. 이건 실행가능한 바이너리가 아니기 때문입니다.

- 섹션헤더 정보다.
- 총 5개의 섹션 엔트리가 존재한다.

- 파일 사이즈는 396바이트
